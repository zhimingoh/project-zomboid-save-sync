## P2 - 可选优化（锦上添花）

### [P2-1] 快照文件与 manifest 不是跨进程事务
- **类型**：架构限制
- **位置**：`server/src/server.mjs` 快照发布段
- **描述**：单进程内并发已经串行化，但进程在移动 ZIP 与写 manifest 之间被强制终止时，文件与 manifest 仍可能短暂不一致。这是现有文件存储架构限制；当前部署为单 Node 进程，本 Change 未引入多进程发布。
